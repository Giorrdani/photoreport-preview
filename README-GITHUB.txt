Фотоотчёт — статическая демонстрация интерфейса для GitHub Pages.

Загрузите СОДЕРЖИМОЕ архива в корень публичного репозитория photoreport-preview.
Settings → Pages → Deploy from a branch → main → /(root) → Save.
Адрес: https://ВАШ-ЛОГИН.github.io/photoreport-preview/

Это только просмотр интерфейса. Нет Spring Boot, реальной авторизации, базы, отправки отчётов, операций со складом.
Данные в формах не отправляются на сервер. Не вводите настоящие PIN или пароли.
Навигация по экранам — нижняя панель «Демо».
